# ED Touch Portal v0.1.0-beta

First public beta of the Elite Dangerous plugin and page set for Touch Portal.

## Downloads
- **ED-TouchPortal-Plugin-v0.1.0-beta.tpp**: import it in Touch Portal → Settings → Plug-ins → Import plug-in. Needs **Node.js 18+**.
- **ED-TouchPortal-Pages-v0.1.0-beta.zip**: unzip it and run `install.ps1` with Touch Portal closed.

## What's in it
- 14 pages: Flight, Nav, Combat, Explore, Trade, Powerplay, CMDR, Camera, On Foot, Carrier & Squadron, Utils and SRV, plus the Loadout and Station subpages
- 261 live states, 125 events and 8 utility actions, all in English

## Known issues
- Credits and Powerplay merits-to-next-rank are approximations.
- After installing, restart Touch Portal completely and fully reconnect the tablet.
- Page file names are still in Spanish (everything shown on screen is in English).

The full list is in the README. Please report bugs in Issues.
